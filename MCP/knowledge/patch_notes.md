# Patch Notes

Document any custom patches applied to this ROM that change game mechanics.
The AI needs to know about these to generate valid level designs.

## Active Patches
(None by default. Add your patches here.)

Example format:
### Patch Name
- **Description**: What the patch changes
- **Affected Systems**: Entities, Doors, Tilesets, Camera, etc.
- **New Mechanics**: Any new gameplay elements added
- **Modified Behavior**: How existing mechanics are changed
- **New Limits**: Any new constraints (e.g., max entities per room changed)

## Vanilla Behavior Assumptions
Unless overridden by patches above, the AI assumes:
- Standard WL4 physics (jump height, movement speed, etc.)
- Max 16 rooms per level
- 3 difficulty modes (Hard, Normal, S-Hard)
- Standard door types and behavior
- Standard entity behaviors as documented in entity_catalog.json
